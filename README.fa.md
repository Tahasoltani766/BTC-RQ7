## 🦠 معرفی

**BTC-RQ7** یک پروژه تحقیقاتی در حوزه امنیت سایبری است که نشان می‌دهد چگونه فعالیت مخرب **Cryptomining** می‌تواند در قالب یک ابزار ظاهراً معتبر و مرتبط با کیف پول‌های رمزارزی پنهان شود.

این پروژه برای نمایش یکی از سناریوهای رایج در **مهندسی اجتماعی و انتشار Malware** ایجاد شده است:

**یک Payload مخرب به کاربر به‌عنوان یک ابزار قانونی در حوزه امنیت یا رمزارز ارائه می‌شود، در حالی که در پس‌زمینه فعالیت‌های غیرمجاز انجام می‌دهد.**

هدف اصلی از انتشار Open Source این پروژه، **افزایش آگاهی امنیتی، تحلیل Malware، توسعه قابلیت‌های تشخیص (Detection Engineering) و تحقیقات دفاعی** است.

این پروژه **برای دسترسی غیرمجاز، سرقت منابع سیستم، Cryptojacking یا استقرار روی سیستم‌هایی که مجوز صریح برای آن‌ها وجود ندارد، طراحی نشده است.**

## 🎯 اهداف تحقیقاتی

BTC-RQ7 با هدف نمایش موارد زیر توسعه داده شده است:

* نحوه پنهان‌سازی نرم‌افزار مخرب در قالب یک برنامه ظاهراً قانونی
* نحوه سوءاستفاده از ابزارهای مرتبط با رمزارز به‌عنوان یک مکانیزم برای انتشار Malware
* نحوه پنهان ماندن فعالیت‌های غیرمجاز Cryptomining از کاربر
* بررسی Artifactها و رفتارهایی که تیم‌های دفاعی می‌توانند مورد تحلیل قرار دهند
* نحوه شناسایی فعالیت‌های مشکوک مربوط به Process و منابع سیستم توسط تحلیل‌گران SOC
* استفاده از Malware Analysis برای بهبود قابلیت‌های تشخیص در Endpointها

هدف این پروژه کمک به پژوهشگران و تیم‌های دفاعی برای درک این موضوع است که **چگونه یک ابزار ظاهراً قانونی می‌تواند رفتار مخرب خود را پنهان کند.**

```text
کاربر
  │
  ▼
ابزار جعلی / مخرب Wallet
  │
  ├──► قابلیت‌های ظاهراً قانونی
```

## 🛡️ مدافعان باید به چه مواردی توجه کنند؟

تیم‌های امنیتی هنگام تحلیل Malwareهای مشابه باید به جای اعتماد به ظاهر برنامه، روی **شاخص‌های رفتاری (Behavioral Indicators)** تمرکز کنند.

برخی از نقاط مناسب برای Detection عبارت‌اند از:

### فعالیت Processها

موارد زیر می‌توانند مشکوک باشند:

* Processهایی با مصرف غیرعادی و بالای CPU
* اجرای Executableهای ناشناخته توسط برنامه‌های دارای رابط کاربری
* ایجاد Child Processهایی که از نظر منطقی ارتباطی با Parent Process ندارند
* اجرای Executableها از مسیرهای غیرمعمول
* Processهایی با Command-line Argumentهای مشکوک

### مصرف منابع سیستم

Cryptominerها معمولاً باعث مصرف قابل توجه منابع سیستم می‌شوند.

شاخص‌های احتمالی:

```text
مصرف بالای CPU
مصرف غیرمنتظره GPU
مصرف مداوم منابع سیستم
کاهش محسوس Performance سیستم
فعالیت غیرعادی فن سیستم
افزایش غیرمنتظره مصرف انرژی
```

### فعالیت شبکه

موارد زیر را بررسی کنید:

* Connectionهای خروجی غیرمنتظره
* Connection به زیرساخت‌های مرتبط با Mining
* Connectionهای دائمی از برنامه‌هایی که معمولاً نباید ارتباط شبکه‌ای داشته باشند
* درخواست‌های DNS مشکوک
* Portها یا Protocolهای غیرمعمول مقصد

### Persistence

تیم‌های دفاعی باید بررسی کنند که آیا اجزای مشکوک تلاش می‌کنند پس از موارد زیر همچنان فعال باقی بمانند یا خیر:

* Reboot سیستم
* Logoff کاربر
* بسته شدن برنامه

## 🔍 تحلیل Malware

برای تحلیل ایمن این پروژه، از یک محیط آزمایشگاهی کاملاً ایزوله استفاده کنید.

### محیط پیشنهادی

```text
                    ┌─────────────────────┐
                    │   سیستم تحلیل      │
                    │                     │
                    │    Windows VM       │
                    │    Procmon          │
                    │    Process Explorer │
                    │    Wireshark        │
                    │    Sysmon           │
                    │    x64dbg           │
                    │    Autoruns         │
                    └──────────┬──────────┘
                               │
                         شبکه ایزوله
                               │
                    ┌──────────▼──────────┐
                    │ سیستم‌های تحلیل و  │
                    │       Logging      │
                    └─────────────────────┘
```

### اقدامات احتیاطی پیشنهادی

* از یک Virtual Machine قابل حذف استفاده کنید
* قبل از شروع تحلیل از VM Snapshot تهیه کنید
* از Wallet یا Credentialهای شخصی استفاده نکنید
* VM را به شبکه سازمانی یا شبکه مورد اعتماد متصل نکنید
* ترافیک شبکه را تحت نظر داشته باشید
* ایجاد Processها را مانیتور کنید
* تغییرات File System را بررسی کنید
* تغییرات Registry را مانیتور کنید
* پس از پایان تحلیل، VM را حذف یا به Snapshot قبلی بازگردانید
