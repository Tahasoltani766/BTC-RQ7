## 🦠 Overview

**BTC-RQ7** is a malware research project demonstrating how a malicious cryptocurrency-related application can be disguised as a legitimate-looking **Wallet Hunter** utility.

The application presents itself as a wallet-related tool while executing a **cryptomining payload in the background**.

The core behavior demonstrated by this project is:

```text
User
  ↓
Wallet Hunter Application
  ↓
Malicious / Hidden Execution
  ↓
Cryptominer
  ↓
Unauthorized CPU/GPU Resource Consumption
  ↓
Cryptocurrency Mining
  ↓
Mining Revenue
  ↓
Attacker-Controlled Destination Wallet
```

In other words, the victim believes they are running a cryptocurrency-related utility, while the application is also using the system's computing resources for **unauthorized cryptocurrency mining**.

The cryptocurrency generated by the mining activity is directed to a **destination wallet controlled by the operator of the mining infrastructure**.

This project is intentionally published as a research sample so security researchers and defenders can inspect the code and understand the behavior behind this type of threat.

## 🎯 Research Objectives

BTC-RQ7 demonstrates several concepts commonly encountered during malware analysis:

* Disguising malicious software as a legitimate cryptocurrency utility
* Executing a cryptocurrency miner alongside visible application functionality
* Consuming victim system resources for unauthorized mining
* Redirecting mining revenue to a predefined destination wallet
* Studying malicious process execution and process relationships
* Identifying abnormal CPU/GPU utilization
* Investigating suspicious network connections associated with mining
* Developing SIEM, EDR, and endpoint detection rules
* Training SOC analysts to identify cryptomining activity

The primary objective is **defensive research**, not unauthorized deployment.

## ⛏️ Cryptomining Behavior

One of the primary behaviors demonstrated by BTC-RQ7 is **unauthorized cryptocurrency mining**.

After the malicious execution path is triggered, the malware launches a mining process that consumes system resources.

The basic relationship is:

```text
Victim Machine
      │
      ├── CPU/GPU Resources
      │
      └── Cryptominer
              │
              ↓
        Mining Infrastructure
              │
              ↓
       Cryptocurrency
              │
              ↓
      Destination Wallet
```

The destination wallet represents the wallet configured to receive the cryptocurrency generated through the mining operation.

From a defender's perspective, this creates several observable indicators:

* Unexpected high CPU utilization
* Unexpected GPU utilization
* Long-running mining processes
* Suspicious child processes
* Network connections associated with mining infrastructure
* Unusual outbound traffic
* Performance degradation
* Increased power consumption
* Application behavior unrelated to its advertised purpose

## 🛡️ What Defenders Should Look For

### Process Activity

Investigate:

* Unexpected high-CPU processes
* Unknown executables launched by user-facing applications
* Suspicious parent/child process relationships
* Executables running from unusual directories
* Processes unrelated to the application's advertised functionality
* Suspicious command-line arguments

### System Resource Usage

Look for:

* Sustained CPU utilization
* Unexpected GPU utilization
* System performance degradation
* Abnormal fan activity
* Unexpected power consumption
* Resource consumption immediately after launching an apparently legitimate application

### Network Activity

Investigate:

* Persistent outbound connections
* Connections to suspicious mining infrastructure
* Unexpected DNS requests
* Unusual ports or protocols
* Network activity inconsistent with the application's advertised purpose

### Persistence

During analysis, investigate whether the malware attempts to survive:

* Reboots
* User logoff
* Application termination
* Process termination

* Windows virtual machine
* Process Monitor

* Sysmon
* Wireshark

* SIEM / EDR telemetry
* Isolated or controlled network

### Recommended Safety Precautions

* Use a disposable virtual machine
* Take a snapshot before execution
* Never use personal cryptocurrency wallets
* Never use personal credentials
* Never connect the sample to a corporate network
* Monitor process, network, filesystem, and registry activity
* Revert or destroy the VM after analysis

## 📚 Why Open Source It?

Malware becomes more dangerous when defenders cannot understand how it works.

BTC-RQ7 is publicly available so researchers, SOC analysts, students, and defenders can:

```text
Inspect the Code
       ↓
Understand the Behavior
       ↓
Identify Indicators
       ↓
Build Detection Rules
       ↓
Improve Defensive Capabilities
```

The goal is **not to make malware more effective**.

The goal is to make defenders more capable of recognizing applications that appear legitimate while performing malicious activity in the background.
